03 · DeepSeek Harness (DSH) — empat mod

DSH ialah orkestrator ejen berasaskan rangka kerja plugin Cordis. Ia bukan “chat” — ia lapisan plugin tersusun yang menjalankan ejen, aliran kerja, sub-ejen, RALPH dan automasi. Pakej yang dipasang pada mesin ini: @deepseek-ai/dsh 0.1.1-rc.2 — versi ini diukur terus daripada package.json dalam pemasangan npm global, bukan daripada dokumen.

#ModStatusPerintahKegunaan
1Web (UI pelayar)Adadsh webKerja interaktif penuh — perbualan, ejen, aliran kerja, plugin, sub-ejen
2Headless (satu tugasan)Adadsh --profile headless "tugas"Automasi skrip/CI, batch, ujian, integrasi program lain
3TUI (UI terminal)Belum dipasangdsh --profile tuiKerja interaktif tanpa pelayar — sesuai untuk pelayan / SSH
4Kustom / PluginCipta sendiridsh plugin --profile <nama>Profil khas projek (cth. profil MyGuruKSSR) dengan plugin terpilih

Anggaran kos setiap mod

DSH sendiri percuma (sumber terbuka) — kosnya ialah kos model LLM yang digunakan. Dokumen sumber sendiri melabel angka ini [ANGGARAN]; ia dikekalkan sebagai anggaran di sini.

ModKos asasAnggaran tugasanNota
WebModel sahaja~RM0.01–0.50Ikut tugasan + bilangan alat
HeadlessModel sahaja~RM0.01–0.10Satu sesi pendek
TUIModel sahaja~RM0.01–0.50Sama dengan Web
KustomModel + pluginBergantungPlugin boleh ada kos sendiri

Faktor kos yang direkodkan: model murah (V4-Flash) ≈ RM0.005–0.05/tugasan · model mahal (Kimi K3, Pro) lebih tinggi · sub-ejen/rantai panjang = gandaan token · waktu luar puncak = 50% lebih murah.

Penjana arahan headless

Alat bantu untuk menulis perintah headless dengan betul. Halaman ini tidak memanggil DSH — ia hanya menyediakan arahan untuk anda jalankan sendiri.


      
Kenapa tidak dijalankan dari sini? Halaman ini dibuka melalui
        file://. Pelayar menyekat permintaan rentas-asal daripada halaman file://
        ke http://127.0.0.1, jadi sebarang “panggilan hidup” yang dipaparkan
        di sini hanya akan menjadi simulasi. Arahan sebenar disediakan untuk dijalankan dalam terminal.

Dua perangkap yang direkodkan

      
Perangkap 1 — 502 palsu daripada proksi. Sesi ini mempunyai
        http_proxy=http://127.0.0.1:51702. Melalui proksi itu, curl biasa
        memulangkan 502 walaupun pelayan sebenarnya hidup, kerana proksi tidak boleh menembusi
        loopback. Sentiasa guna curl --noproxy '*' untuk menguji pelayan
        tempatan. 502 daripada proksi bukan bukti pelayan mati — dan 200 daripada proksi pun bukan
        bukti pasti ia hidup.

      
Perangkap 2 — batasan host. Host membunuh seluruh pokok proses pada
        setiap sempadan panggilan alat. Eksperimen yang direkodkan: nohup ... &,
        Start-Process, cmd /c start /B dan
        DETACHED_PROCESS|CREATE_BREAKAWAY_FROM_JOB semuanya dibunuh; schtasks
        dan WMI Win32_Process.Create disekat oleh polisi keselamatan.
        Kesannya: proses yang perlu kekal hidup mesti dilancarkan oleh pengguna, bukan oleh sesi
        automasi.
